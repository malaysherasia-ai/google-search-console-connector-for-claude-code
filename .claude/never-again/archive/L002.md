# L002: optional DOM children render as "null"

**Symptom:** The word "null" appeared in table footers (dashboard) and above the sign-in card (Connect page).

**Cause:** `Element.replaceChildren(...)` converts every non-Node argument to a text node, so `cond ? el : null` or `x && el` children become the strings "null"/"undefined"/"false". The project's `h()` helper filters these, so code written in the same style but passed to `replaceChildren` broke. It happened twice in one session, in two files.

**Rule:** In web/assets, use `fill(el, ...children)` from common.js (filters null/undefined/false); never call `.replaceChildren(` directly outside common.js.

**Fix:** Added `fill()`; replaced all 41 call sites.

**What would have gone red:** nothing; only screenshot review. Hence a commit hook (warn) that flags `.replaceChildren(` in changed web/assets/*.js other than common.js.
