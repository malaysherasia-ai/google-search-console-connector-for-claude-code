# L003: Drop deprecated Google API fields before returning them

**Symptom:** On the first live run (a real property, 2026-10-13), `gsc_list_sitemaps` reported 23 pages submitted and `indexed: "0"` while URL Inspection showed the homepage "Submitted and indexed". `gsc_inspect_url` returned `mobileUsabilityResult: VERDICT_UNSPECIFIED`. Both read to Claude as problems with the site.

**Cause:** `src/gsc.ts` returned Google's raw responses. The Sitemaps API's `contents[].indexed` is deprecated and no longer populated (always "0"); Mobile Usability was retired in December 2023 but the Inspection API still returns an empty verdict. Demo data never contained either field, so demo-mode testing could not show it.

**Rule:** Before returning a Google API response to Claude or the dashboard, check the API reference for deprecated or unpopulated fields and drop them in `src/gsc.ts`.

**Fix:** `listSitemaps` strips `contents[].indexed`; `inspectUrl` deletes `mobileUsabilityResult`; the `gsc_inspect_url` description no longer promises mobile usability.

**What would have gone red:** nothing. Only a live response shows it; demo data is hand-written from the current docs.
